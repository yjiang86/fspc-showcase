# Contributions And Attribution Limits

The project is human-directed and agent-assisted. Code, tests and documentation
were developed through iterative engineering work; automated assistance is not
presented as independent experimental validation.

The division of responsibility is:

- Human project ownership: problem selection, intended rig constraints,
  integration priorities and acceptance of work.
- Agent-assisted implementation: scaffolding, contract and adapter maintenance,
  refactoring, tests, documentation and reproducible evidence organization.
- This showcase preparation: bounded source selection, dependency trimming,
  portable examples and privacy checks. It does not add a new research method.

This is a responsibility description, not an independently audited statement
that every component was personally implemented by one individual. Detailed
per-component human contributions and institutional ownership have not been
confirmed in this delivery. A recruiting discussion should distinguish personal
design decisions, reviewed agent output and physical work actually performed.

Export commit metadata is deliberately neutral; it is not a substitute for
the original authorship record. Original source provenance is retained by the
project owner outside this recruiter-facing subset.
